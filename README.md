# Public-File-Access
Just a small area for storing files that need storing.

If a file is in this repository that means its already a publicly accessable file and this is not illegal reposting or anything. The reason for this repository is so there is a place for wiki links to direct to as well as collecting some files that can be harder to access for mac users and others.

Files can easily be downloaded by clicking on the file you want and looking to the top right for a download raw file button.
